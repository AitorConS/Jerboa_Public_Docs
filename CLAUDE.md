# docs.jerboa.dev (Jerboa_Public_Docs): frontend guide

## Skills for frontend work

Two skills shaped this design. Use them for any UI change. `npx` is not installed on this Mac, so run them through `pnpm dlx`:

- **ui-web** (rshzrh/ui-design-skills): builds the UI from tokens and runs the token and UI audits.
  ```bash
  pnpm dlx skills use "https://github.com/rshzrh/ui-design-skills" --skill "ui-web"
  ```
  This repo is in *extend* mode: read `DESIGN_RULES.md`, use only existing tokens, and ask before adding any. Before calling UI work done, print its UI Audit table, with every check passing.
- **web-design-guidelines** (vercel-labs/agent-skills): reviews code against Vercel's Web Interface Guidelines (accessibility, focus, forms, motion, typography, performance, copy).
  ```bash
  pnpm dlx skills use "https://github.com/vercel-labs/agent-skills" --skill "web-design-guidelines"
  ```
  It fetches the current rules from `https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md` and reports findings as `file:line`.

## Jerboa style rules

`DESIGN_RULES.md` is the full contract; these are the rules that matter most.

- **Anchor:** Linear / Vercel / Geist, shared by jerboa.dev, docs.jerboa.dev and Jerboa Desktop.
  - stone neutrals, dark only (`color-scheme: dark`);
  - Geist for text and display, Geist Mono for code and labels;
  - the brand accent below.
- **Tokens only.** No literal colours, lengths, durations or arbitrary values outside the token file. If a value is missing, stop and ask for a token.
- **Elevation is a 1px border.** No shadows, blur, glass or gradients. One bordered level at most: no card in a card.
- **Type:** seven sizes (12, 14, 16, 20, 24, 32, 48 px).
  - Display text in weight 600 with tight tracking.
  - Small mono uppercase labels.
  - Tabular figures for numbers.
- **Motion:** 60 ms for hover, 120 ms for layout, 180 ms for dialogs.
  - No entrance animations, rotating words, pulses or autoplay.
  - Everything respects `prefers-reduced-motion`.
- **Accessibility:**
  - visible focus (2px outline, 2px offset);
  - a skip link and one `h1` per page, with headings that never skip a level;
  - ≥ 44px tap targets on the web, ≥ 32px controls in the desktop app;
  - icon-only controls labelled;
  - AA contrast for text (4.5:1) and UI (3:1).
- **Copy:**
  - terse, present tense, technical, sentence case, second person;
  - numbers only when they were measured, with the machine and test named;
  - no filler ("Lightning fast", "Powered by AI"…), no generic CTAs ("Get Started", "Learn more"), no buzzwords (clean, modern, sleek, premium…);
  - if real copy is missing, ask.
- **Data honesty:** comparisons with Docker show losses as well as wins, and link to the method.

## This repo

- **Stack:** Astro, plain CSS with custom properties. Tokens: `src/styles/tokens.css` and `src/styles/global.css`, both identical to Jerboa_Docs (jerboa.dev). The documentation pages in `src/pages/*.md` are generated by `pnpm run docs:sync` from `jerboa/docs`: style them through `src/layouts/Docs.astro`, never by editing the Markdown.
- **Accent:** **amber-600** `--accent` (#d97706), in text only: the active nav link, the current page in the sidebar and the current section in "On this page", article links, and commands in code blocks (Shiki's function token). **Never** on the borders of blocks; the sidebar and index marker lines stay neutral.
- Page text, titles and meta descriptions are written in `jerboa/docs/*.md` (frontmatter `title` and `description`); this repo only syncs them.
- Code blocks use Shiki's `css-variables` theme mapped onto the stone tokens in `Docs.astro`; do not switch to a coloured Shiki theme.
- SEO: one description per page, titles lead with the page name, TechArticle and BreadcrumbList JSON-LD, and `/` stays out of the sitemap (it is an edge redirect in `vercel.json`).

## Before calling UI work done

```bash
pnpm run lint:design   # must report 0 problems
JERBOA_SOURCE=../jerboa pnpm run docs:check
pnpm run build
```

Check the result at 1440 and 390 px (no horizontal scroll, no console errors), then print the ui-web UI Audit table.
